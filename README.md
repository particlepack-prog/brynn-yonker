# Brynn Yonker — Portfolio

Static site for Brynn Yonker, production sound mixer, sound designer and audiobook engineer in Nashville, TN.

Plain HTML, CSS and JavaScript — no build step. Open `index.html` locally, or serve the folder from any static host.

## Structure

- `index.html` — home
- `services.html` — what each service includes
- `work/` — production sound, sound design, audiobooks, Sound Scout
- `css/style.css`, `js/main.js` — shared styles and behavior
- `img/` — drop-in images; see `img/README.txt` for the exact filenames the pages expect
- `audio/` — before/after clips for the Sound Design player (currently placeholders)

## Before launch

- Set the real booking email in `js/main.js` (contact form currently uses a placeholder).
- Replace the placeholder audio in `audio/` with Brynn's real before/after clips.
